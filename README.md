# Shopinvader Opinionated Starter Kit

Shopinvader is made up of several small, generic building blocks. This project offers a ready-to-use, opinionated setup based on these modules.
As it is an opinionated distribution, these apps may not fit all your needs. The aim of this project is not to provide a one-size-fits-all solution, but rather to offer a tailored setup that should cover the most common business cases. If you have specific requirements, you do not need to install these apps. Instead, you can build your own solution and cherry-pick only the needed components from the odoo-shopinvader repository.
Feedback is welcome (please open an issue), but be aware that, as this is an opinionated project, we may not share the same vision of what constitutes a common business case.
